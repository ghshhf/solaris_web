# 索拉丽斯炼成计划 · 网页版

用原作素材 + 原作剧本做的 30 天卡牌肉鸽。

## 怎么开

**双击 `index.html`** 就能玩（纯静态，无依赖，不需要服务器）。

也可以起个本地服务：

```bash
python -m http.server 8891
# → http://127.0.0.1:8891
```

## 玩法

照原作的三角结构做的，不是照搬杀戮尖塔：

| 原作机制 | 这里的实现 |
|---|---|
| 每天从卡里选一张 | **探索 / 战斗 / 交流 / 休息 / 学习 / 商店 / 行装**，探索必出，其余随机三张 |
| 出卡片 → 霍姆执行 | 战斗内每回合抽 3 张招式卡，**点卡即出招** |
| 玩家指挥霍姆 | 不设左右判定条，点一下直接结算 |
| 七系招式各有升级线 | 每系 11 级，名字逐级变化，越用越熟 |
| 羁绊越高越顺手 | 羁绊 1→5，折算成 1.00→1.20 倍出招倍率 |
| 索拉丽斯能放强力魔法但有代价 | 「接手」按钮：耗 10 HP，伤害固定 16+ |
| 五个 Boss 节点 | 第 6 / 12 / 18 / 24 / 30 天 |

出招随机（没有需要按的判定）：

| 结果 | 概率 | 倍率 |
|---|---|---|
| 会心 | 18% | ×1.5 |
| 平常 | 70% | ×0.92 ~ ×1.12 |
| 手滑 | 12% | ×0.7 |

剧情对话框底部有 **跳过这段 ▶▶**，一下跳到该段剧情的收尾（直接进战斗 / 结算），不用一句句点。

### 探索（核心玩法）

6 个区域，共 33 层。每层随机给敌人 / 金币 / 回复 / 陷阱，走到底打首领。

| 区域 | 层数 | 开放 | 底图 |
|---|---|---|---|
| 荒野 | 4 | 第 1 天 | 白天 |
| 森 | 5 | 第 1 天 | 白天 |
| 森洞窟 | 5 | 第 8 天 | 夜晚 |
| 火山 | 6 | 第 15 天 | 强敌 |
| 海洞窟 | 6 | 第 20 天 | 夜晚 |
| 试炼之仪 | 7 | 第 26 天 | 战斗 |

每层三个动作：**前进**（推进 / 遇敌）、**搜刮**（每层一次，得金币或道具）、**撤返**（收工结算）。
打赢首领后该区域计一次通关，可以反复刷。

### 商店（奥加斯特的店）

进店算一天。**3 件货**：1 件消耗品 + 1 件装备（只出还没拥有的）+ 1 本招式书。同一天可以边买边帮工，帮工只能一次。

| 消耗品 | 效果 | 价 |
|---|---|---|
| 练习用短剑 | 力量 +3 | 22 |
| 旧皮护甲 | 防御 +3 | 22 |
| 治愈药水 | 回复 24 体力 | 16 |
| 护身符 | 体力上限 +12 并补上这 12 点 | 28 |
| 热茶与点心 | 回复 14 体力，羁绊 +1 | 26 |
| 磨刀石 | 力量 +2、防御 +1 | 18 |
| 招式书·某系之书 | 该系熟练度 +3（约升 1–2 级，随机一系） | 30 |

底部三个键：**帮工半天**（+8~18 金，随羁绊涨）、**行装**（换装备）、**离开商店**。

### 音乐

8 首原作 BGM 按场景切：标题 / 白天 / 夜晚 / 森林 / 商店 / 战斗 / 强敌 / 结局。右上角喇叭可以静音。

### 七系 × 11 级（名字逐条对照原作 `HomuMotion.csv` 译出）

| 系 | Lv1 → Lv11 |
|---|---|
| 剑 | 攻击 → 斩击 → 舍身 → 破坏 → 破铠 → 破刃 → 无双连击 → 舍身一击 → 破坏一击 → 碎盔 → 碎剑 |
| 盾 | 防御 → 守护构 → 破邪构 → 待魔构 → 不屈构 → 治愈构 → 仁王构 → 破邪守护 → 待魔守护 → 不灭之笼 → 治愈之笼 |
| 毒 | 毒突 → 要害突 → 毒素一闪 → 毒素之笼 → 火焰突 → 火焰之笼 → 致命一击 → 剧毒一闪 → 剧毒之笼 → 业火突 → 灼热之笼 |
| 拳 | 治愈拳 → 再生拳 → 魔力拳 → 闪耀拳 → 抚愈拳 → 安宁拳 → 苏生拳 → 篡夺拳 → 幻惑拳 → 奇迹拳 → 祈祷拳 |
| 蓄 | 蓄力 → 激怒 → 暴走 → 力量提升 → 应援 → 垫步 → 月光 → 超载 → 极限突破 → 决胜台词 → 准备万全 |
| 袭 | 偷袭 → 影缝 → 玩火 → 剧毒警告 → 削弱 → 惊吓 → 影缚 → 玩火奥义 → 阿鼻叫唤 → 麻痹一击 → 妨碍工作 |
| 棘 | 荆棘林 → 荆棘盾 → 针席 → 要害刺 → 威吓针 → 苦痛针 → 刃大盾 → 枪衾 → 针治疗 → 恐怖针 → 苦难针 |

每系主数值随等级线性上涨（剑 6→28，盾 8→26，拳 8→30，袭 5→22），升一级换名换数值。
熟练度按 `[1,2,3,5,7,9,11,13,15,17]` 十档递增，满级累计 83 次——前三级几场战斗就能摸到。

出招会播原作的招式特效帧（一击 / 二击 / 三击 / 大振 / 强拳 / 无双连击 / 落下 / 贯通，各 6 帧）。

结局按羁绊分支：≥4 走羁绊结局，2–3 普通结局，<2 或战败走坏结局。

## 测试

```bash
node tools/selftest.js
```

最小 DOM 桩 + `vm` 沙箱，跑通 开场（含跳过）→ 首战 → 点卡即结算 → 升级 → 随机分布 → 商店买卖 → 敌人帧动画 → 状态系统 → 探索 6 区域 → 装备装卸 → 30 天流程 → 结局判定。当前 **131 项全通过**。素材缺失会自动报出具体表情名与帧号。

游戏脚本整体在 IIFE 里，外部拿不到内部符号，所以 `index.html` 末尾挂了一个只读钩子 `window.__T__`（招式树、熟练度、当前战斗状态、探索与装备接口），仅供测试读取，不影响玩法。

## 素材来源

立绘、背景、敌人动画、招式特效、状态图标、BGM、台词全部从《索拉丽斯炼成计划 / Project Solaris》（Greenhorn 开发，IndieArk 发行）本机文件中提取，未做任何重绘或改写。

原包解压约 2 GB，其中 94% 是两个 `.resS` 里的裸 RGBA 像素。这里按用处重编码成 WebP / MP3，最终 **17 MB**。
